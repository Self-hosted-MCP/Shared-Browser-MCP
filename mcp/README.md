# Shared-Browser-MCP: the door (`mcp`)

The MCP server of [Shared-Browser-MCP](https://github.com/Self-hosted-MCP/Shared-Browser-MCP), in Python. Your AI app connects here.
It runs as one of six containers. Setup, safety and every guide are in the [main README](https://github.com/Self-hosted-MCP/Shared-Browser-MCP#readme).

Run the tests:

```bash
uv run pytest -q
```
